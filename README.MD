<center><p style="text-align: center;">This Minecraft mod makes you able to smelt Sand into Glass in a blast furnace, which means you can smelt Sand at 2x speed.<br />Blast Furnaces are in real-world used to melt sand into glass so it would make sense if it was the same in Minecraft.&nbsp;</p>
<p style="text-align: center;"><img src="https://i.imgur.com/aqTJhBa.png" alt="" width="364" height="267"/></p></center>
<details>
<summary><strong>Configuration</strong></summary>
<p>You can configure this mod directly in-game or edit the JSON file <code>config/blastingsand.json</code> in your profile folder. Please note that any changes will require restarting Minecraft to take effect.</p>
<center><p style="text-align: center;"><p style="text-align: center;"><b>sand_list</b> - List of Blocks you can blast into Glass</p></center>
